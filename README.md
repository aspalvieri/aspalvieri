# Alex Spalvieri Portfolio

A compact, single-page portfolio focused on Dawnhold. The site is a static React application built with Vite and deployed through Google App Engine.

## Local development

Run commands from the `client` directory:

```powershell
npm install
npm run dev
```

The development server runs at `http://localhost:3000`.

## Production

```powershell
npm run build
npm run preview
```

The production build is written to `client/dist`. Deploy with `npm run deploy` from the `client` directory.
