# Client (Vite + React 18)

## Scripts

- `npm run dev` (or `npm start`): start local dev server on `http://localhost:3000`
- `npm run build`: build production assets to `dist/`
- `npm run preview`: preview the production build locally
- `npm run deploy`: build and deploy to Google App Engine

## Environment Variables

- `VITE_RECAPTCHA_SITE_KEY`: reCAPTCHA site key override (optional)

## API Base URL

- `development`/`test`: `http://localhost:5000`
- `production`: `https://api-dot-plucky-rarity-339004.uc.r.appspot.com`
